# JobRoutee - Job Recruitment System

## Project Description

JobRoutee is a Java Swing-based desktop application developed to streamline the recruitment process between job seekers and recruiters.

The system provides separate interfaces for Administrators, Recruiters, and Job Seekers.

## Features

### Admin
- Manage recruiters
- Manage job seekers
- Monitor recruitment activities

### Recruiter
- Post job vacancies
- Review applications
- Accept or reject candidates

### Job Seeker
- Register and log in
- Upload resumes
- Apply for jobs
- Track application status

## Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Eclipse IDE
